## 7. 键盘与焦点（本项目可聚焦 DOM 元素 = 0，规则按口径登记）
| 项 | 定法 | 本项目落点 |
| :-- | :-- | :-- |
| Tab 顺序 | 与视觉顺序一致、禁正数 `tabindex` | `N/A`（零 DOM 控件）；原生菜单内的方向键由系统处理 |
| Esc | 关闭最上层浮层并把焦点还给触发它的元素 | 原生菜单是系统行为（Tauri `popup` 由 OS 绘制）；焦点回窗口本身（WebView 无 DOM 焦点可还） |
| Enter | 表单内不提交（提交只认按钮）、搜索框提交查询 | 原生菜单项按 Enter 激活 = 系统行为；本项目无表单 |
| 焦点环 | `outline: 2px solid var(--color-focus); outline-offset: 2px;` + 静止态预留 `outline: 2px solid transparent` 防几何跳变；**0 ms 瞬时出现、禁止渐显**；禁止用 `border` 或 `box-shadow` 冒充 | `N/A`（零可聚焦 DOM 元素）；上面两行是将来引入任何可聚焦元素时的唯一写法；`--color-focus` 由 3-5 给值（对元素背景与页面底色都 ≥3:1） |

- **可访问性缺口（本卡新发现，登记不修）**：唯一动作「退出」的鼠标路径 = 右键菜单；键盘路径 = **Alt+F4**（Windows 标准 `WM_CLOSE`，不经 IPC、不需额外权限）。判据：在猫身上按一下让窗口获得焦点 → Alt+F4 → 进程退出且任务管理器无残留。4-1 批次 0 顺手观察、4-3 键鼠清单逐条核；若实测不通，7-6 卡的可访问性清单必须写"未满足"，不许默认它成立。

| 态 | 触发 | 本项目落点 |

## 10. 触控与目标尺寸（三口径同时成立）
- ① Web 指针目标 ≥24×24 CSS px（WCAG 2.2 AA）② 触控目标 ≥44×44 pt（iOS）/ 48×48 dp（Android）③ 相邻触控目标间距 ≥8 px。
- 本项目落点：唯一指针目标 = **猫身绘制形状的并集**（视口 260×300，取 `characterBounds()` 的外接矩形）。① 成立，且无需为细部件（耳尖 / 尾尖）另设下限——拖拽与右键接受猫身任意点、判据是并集；并集 ≥24×24 可由 M3 已冻结的比例断言推出（两眼合并宽 ≥ 头宽 60%、耳距 ≥ 头宽 55%、尾长 ≥ 体高 120%），故不新增用例。② ③ `N/A（理由：桌面指针设备，无触控目标、无相邻元素）`。

## 11. 页面与布局纪律、图标 / 数字 / 标点
- 页面与布局纪律：`N/A（理由：本项目没有"页面"——整窗只有一只 SVG 猫，没有 hero、没有区块、没有导航、没有页脚）`。口径登记备用：主页面 ≥8 区块时至少 4 种布局族、hero 桌面顶部内边距 ≤6 rem、整页居中元素 ≤2 个、单页单主题单主 CTA、禁三列等宽功能卡、禁"wordmark + 4~5 内联链接 + 右侧按钮 + 1 px 发丝线"的 AI 导航 / 页脚指纹。
- 图标：零图标库、零 emoji——角色是自绘 SVG（M3），不是图标；将来引入图标只允许一个库 + 一种 `strokeWidth`，图标按钮必须有 `aria-label`。
- 数字：摆件不显示任何数字 → `tabular-nums` 口径在此登记（将来出现数字列 / 计时时的唯一取法）。
- 标点与格式：真引号（「」“”）、省略号用单字符 `…`、数字与单位之间不换行空格、**长破折号 0 处**（扫描命令见 §12）；禁装饰性外壳（假窗口边框 / 假浏览器条 / 假终端框 / 无因渐变）——本项目整窗就是内容，没有外壳可假。
