## 2. 唯一的强调色 = 焦点环色（本项目没有品牌面，只有"强调"这一种用色）

| `--color-focus-active` | `#1D4ED8` | 焦点环按下 | 6.70:1 | 3.13:1 |

- **双门禁（本项目特有）**：窗口是透明的，"页面底色"= 用户的桌面壁纸，我们既读不到也不该读 → 强调色必须**同时对纯白与纯黑 ≥3:1**，即相对亮度落在 0.10–0.30 的受限带内。卡内示例的按下档 `#1E40AF` 实测对黑只有 2.41:1，**本项目不采用**；三档里"悬停反而变亮"也是同一原因（深色桌面上"变深"会消失）。
- 写法（`docs/UI.md` §7 已定，本卡只给色值）：`outline: 2px solid var(--color-focus); outline-offset: 2px;` —— **0 ms 瞬时出现、禁止渐显**，禁止用 `box-shadow` 或 `border` 冒充。本期零可聚焦 DOM 元素 → 同为口径登记。
- 配对前景 `--color-brand-ink`（压在强调色上的文字色）= `#FFFFFF` / `#0F0F14`（浅 / 深）；本期无文字压其上，登记备用。禁用项：禁止硬编码 `color: white`，一律引用 `-ink`。

## 4. 对比度门禁（WCAG 2.1 AA 写死；超限一律改取值不改门禁）
- 正文 ≥4.5:1 ｜ 大字 / 图标 / 图形关键元素 ≥3:1 ｜ **图形边界（轮廓冷光、分缝线）≥3:1** ｜ 焦点环 `--color-focus` 对元素底色与"页面底色"（本项目 = 任意桌面壁纸，取纯白与纯黑两端）都要 ≥3:1。任何写了 `background` 的规则必须在同一条规则里写 `color`。
- 可跑命令（改任何一阶都要重跑；色值就是 §1~§3 的取值）：
```powershell
function Get-CR($a, $b) { $L = { param($h) $c = @(1,3,5) | ForEach-Object { [Convert]::ToInt32($h.Substring($_,2),16)/255 }; $v = $c | ForEach-Object { if ($_ -le 0.03928) { $_/12.92 } else { [Math]::Pow(($_+0.055)/1.055,2.4) } }; 0.2126*$v[0]+0.7152*$v[1]+0.0722*$v[2] }; $x = & $L $a; $y = & $L $b; [Math]::Round((([Math]::Max($x,$y)+0.05)/([Math]::Min($x,$y)+0.05)),2) }
foreach ($p in @(@('body','#FFFFFF','#08080D',4.5),@('large','#75758F','#272735',3),@('bound','#66667F','#1C1C27',3),@('focus','#2563EB','#FFFFFF',3),@('focus','#2563EB','#000000',3),@('place','N/A','N/A',4.5),@('sema','#15803D','#FFFFFF',4.5),@('sema','#B45309','#FFFFFF',4.5),@('sema','#B91C1C','#FFFFFF',4.5),@('sema','#1D4ED8','#FFFFFF',4.5),@('sema','#15803D','#DCFCE7',4.5),@('sema','#92400E','#FEF3C7',4.5),@('sema','#B91C1C','#FEE2E2',4.5),@('sema','#1D4ED8','#DBEAFE',4.5),@('sema','#4ADE80','#1C1C27',4.5),@('sema','#FBBF24','#1C1C27',4.5),@('sema','#F87171','#1C1C27',4.5),@('sema','#60A5FA','#1C1C27',4.5))) { if ($p[1] -eq 'N/A') { "$($p[0]) N/A（本项目零占位文字：没有输入框）" } else { $r = Get-CR $p[1] $p[2]; "$($p[0]) $($p[1]) on $($p[2])  $r  $(if ($r -ge $p[3]) { 'PASS' } else { 'FAIL' })  (>= $($p[3]))" } }
```

## 6. 命名规则与禁则
- 命名按角色不按外观：`--color-<语义>-<层级>`（如 `--color-focus`、`--color-brand-ink`、`--color-neutral-500`），层级取 50–900 或 `light/dark`；禁止 `--blue-500` 这类把外观写进名字的 token。
- 颜色字面量只允许出现在 `:root`（或将来真加了主题层时的主题块）里，组件样式里 0 处裸色值；字体族同理走 `--font-*`（本项目零文字 → 不设）。
- 禁止项：纯 `#000000` 与纯 `#ffffff` 作基色（眼白是插画填充、不是基色，且 M3 已冻结它）；三色渐变、紫蓝渐变、渐变文字；浅底纯黑投影与彩色辉光。

## 7. 明暗模式
- `N/A（理由：本项目没有主题层——窗口是透明的，"深 / 浅"由用户的桌面壁纸决定，而壁纸我们既读不到也不该读；没有 HTML 面就没有 [data-theme="dark"] 这样的切换选择器，本文件不定义暗色主题块）`。
- 等价物 = **桌面对比度问题**，已在 §1 / §4 用轮廓冷光解决：黑色本体在浅色桌面上自带 ≥4:1，在深色桌面上靠 300 档冷光 ≥3:1。卡内暗色模式六条（底色 12–18%、文字 92–96%、正文降 50 字重、accent 降 chroma 提亮、elevation 每级 +3%、不换色相）在本项目无对象，登记备用。
- 若将来真加 HTML 面：`:root` 与 `[data-theme="dark"]` 各写一套语义 token（`--color-bg-page` / `--color-text-primary` / `--color-border`），色相不变、只动亮度与 chroma。

## 9. 面积配比（60-30-10 为何不适用 + 本项目的真实配比）
- 卡内 60-30-10（底 60 / 中性 30 / 强调 10）约束的是**版式三层**；本项目没有版面层，只有一只画在透明画布上的猫 → 纪律换成两条：**强调（分缝线 + 冷光边）面积 ≤5%**、**亮色（眼白）只出现在 2 个区域**（M3 冻结断言）。
- 按 §10 的几何实算（椭圆 πab、钟形按梯形近似；画布 320×360 = 115200）：眼白 2×π×45×52 ≈ 14703 → **画布 12.8% / 角色 26.6%**；耳朵 ≈2240 + 头 28902 + 身体 ≈14880 + 腿 ≈6232 + 尾 ≈3000 ≈ 55254 → **画布 48%**；轮廓与分缝线（约 2px 描边、周长 ≈1200）≈ **2.1%**（在 5% 以内）。
- 结论：画布的 **52% 是透明区**——这正是"透明区穿透"能工作的前提；角色本体只占 48%，所以任何"整窗上色"的提案都必然破 M1 的透明要求。

## 10. 角色造型比例与三条冻结断言的语义（4-1 画图依据）
> 设计坐标系 **320×360**，整体等比重心缩放，SVG 元素仍渲染 260 CSS px 宽（缩放 0.8125 → 高 292.5），窗口 300 高 − 292.5 = **底部余 7.5px**（SCOPE §7 写"留 8px"是取整表述）。DESIGN §3.5 的 `VIEW_BOX` 已同批勘误为 `'0 0 320 360'`（原写 `'0 0 260 300'`：身体底沿 y=352 会被裁掉脚）。
- 头部 椭圆 圆心 (160,140)、rx 100 / ry 92 ｜ 眼睛 两椭圆 圆心 x=113 / 207、y=136、rx 45 / ry 52（两眼水平间距仅约 6px，几乎相接）｜ 瞳孔 rx 32 / ry 41，相对眼心偏移 (+2,+4)（偏下让**上眼白更宽**）｜ 鼻子 约 (160,213) 的小圆角倒三角 ｜ 身体 钟形，底宽约 ±74、顶宽约 ±50、底沿 y≈352 ｜ 前腿 宽 38、y 262→344，下方半圆收脚 ｜ 尾巴 沿贝塞尔中心线生成的锥形实体，根部宽 30 → 尖端宽 10，自身体右下向右上兜回。
- **3-5 补的取值（原表缺了它们，M3 判不了）**：耳根中心 x = 100 / 220、耳尖 x = 96 / 224（竖直、略外张 4px）；尾巴**目标弧长** = 408（设计坐标）。**耳距口径写死为"两耳根中心距"** = 120 → 120/200 = 0.60；按耳尖算 = 128/200 = 0.64 —— 两种读法都过 M3 的 0.55。弧长必须由 `tail.pathD` 的贝塞尔采样得到（DESIGN §3.5 已把 `pathD` 加进契约）：**只断言 `lengthPx` 常量 = 同义反复**，不算过。
- **三条冻结断言的语义（写给 4-1 的 `geometry.test.ts`，不许各写各的）**：① 两眼外接矩形合并宽 / 头宽 = 184/200 = 0.92 ≥ 0.60 ② 耳距（两耳根中心距）/ 头宽 = 120/200 = 0.60 ≥ 0.55 ③ 尾长（尾部中心线**弧长**，不是包围盒对角线）/ 体高（**耳尖 y 到身体底沿 y** = 352 − 24 = 328）= 408/328 = 1.24 ≥ 1.20。
- 绘制顺序：① 先用冷光画笔描出所有部件轮廓 → ② 再用实色填充所有部件；后填充的实心块会盖掉内部多余的描边，只留最外一圈（决定轮廓是否干净）。
- 动效（眨眼 / 呼吸 / 甩尾的时长与缓动）归 `docs/MOTION.md`（3-6 卡）；本节只定形象与色。
