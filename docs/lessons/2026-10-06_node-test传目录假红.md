# node --test 传目录 = 假红（Node 24 的位置参数不接受目录）
复发次数: 1
作用域: 本项目（Node v24.21.0 + 内置 node:test）
最近复发: 2026-10-06
现象：`node --test <目录>` 退出码 1，输出 `test at <目录>:1:1` + `✖ <目录> 'test failed'`；但同目录下每个 *.test.ts 单独跑、以及 `node --test`（无参，cwd 默认 glob）都是退出码 0。**与"测试真的红"完全同形**。
根因：Node 24.21 的位置参数不被当作搜索根——目录路径被当成一个待执行的测试文件去跑。
修法：门禁与探针一律用 glob 模式 `node --test "src/**/*.test.ts"`（正/反斜杠实测均可，退出码 0）；不要给目录。判退出码时禁止 `| Select-Object -First N` 截断（会掐死子进程伪造 -1，见 2026-09-11_假exit码）。
下次定位：check.ps1 的 STEPS；以及任何"新加的测试是不是我写错了"的判断之前——先怀疑参数形态，再怀疑测试。
证据：2026-10-06 本项目四条实测：无参 `node --test` → 0；`node --test <目录>` → 1；故意失败的断言 → 1；`node --test "src/**/*.test.ts"` → 0。
来源：2-2 卡开工前的可行性探针（会话内产物，探针目录已按 D7 删除）
