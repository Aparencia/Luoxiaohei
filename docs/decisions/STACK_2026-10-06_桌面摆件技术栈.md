## 选了什么

**Tauri 2 + React 19 + TypeScript（Vite 构建；角色用 SVG + CSS 动画）**

一句话依据：唯一同时满足「用户已用它发过桌面应用版本」「单 EXE 零安装分发」「HTML/SVG 做角色动画远比 GDI+ 好写」三条的栈。

- 前端：React 19 + TypeScript + Vite（`src/`）
- 外壳：Tauri 2（`src-tauri/`，Rust 侧只做窗口控制）
- 运行时：系统 WebView2（不打包浏览器内核）
- 包管理：npm（用户既有项目用 npm + `package-lock.json`；本机无 pnpm）

## 已知风险（用户裁决时已明示并承担）

- **Tauri #15947（OPEN，2026-08-30）**：Windows 上「透明 + 置顶 + 频繁切换鼠标穿透」的**桌面宠物形态**，存在透明区偶发变黑/壁纸变黑的合成竞态。报告环境为 Windows 10、单例、1440×900 WebGL 大窗；本项目为 Windows 11 + 小窗 + SVG，风险面小但**未消除**。来源 <https://github.com/tauri-apps/tauri/issues/15947>（检索日 2026-10-06）
