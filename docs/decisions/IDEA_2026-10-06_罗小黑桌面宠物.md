## 动作 3 · SWOT（每条可验证）

**S（优势）**
1. 零服务器成本、纯本地运行——技术栈为 Windows 自带 .NET Framework，无需 Node / Electron / Live2D 运行时（依据：本会话实测 `Add-Type`、`[System.Windows.Forms.Form]`、`[System.Drawing.Bitmap]` 可用，`csc.exe` 存在）
2. 形象易矢量还原——小黑是纯黑大色块 + 巨型奶白眼白与黑瞳孔的极简设计，色块极少，GDI+ 路径即可表达

**W（劣势）**
1. 无官方美术资源，全靠手绘矢量，还原度有上限
2. 单平台：仅 Windows
3. 无骨骼 / 物理引擎，动态表现力弱于 Live2D 系竞品

**O（机会）**
1. 《学前篇》2026-10-30 B站独播，IP 处于新一轮曝光窗口
2. 头部开源桌宠都是"通用框架 / 工具"，**未发现罗小黑主题的**

**T（威胁）**
1. **版权**：罗小黑是 MTJJ / 寒木春华在版权 IP。自制自用属粉丝行为；用户已选择**公开分发**，公开传播未授权形象的衍生作品存在侵权风险 —— **本次最大风险**
2. 竞品迭代极快：BongoCat 在检索当日（2026-10-06）仍有推送，生态成熟

### ⚠️ 待验证直觉（不是证据，不参与判分）

1. 「桌面上有只会动的小黑会让心情变好」——现在无法验证；最小实验：MVP 常驻桌面两周，记录是否主动去看它
2. 「GDI+ 手绘能达到可接受的还原度」——`src/HeiCat.cs` 已有半成品但**从未渲染验证**；最小实验：渲染一版 PNG 自评
